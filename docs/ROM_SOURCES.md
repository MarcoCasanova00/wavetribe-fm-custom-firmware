# ROM Source Reference — Melting-pot 0.4

These rare synth and drum-machine ROM collections were documented via public
archives and are candidates for further sound synthesis and sampling extraction.

## Obscure synthesizers (future single-cycle / patch sources)
- **Jen Synx 508** — rare Italian poly, aggressive basses and leads  
  - Archive entry: `Jen Synx 508 - Version 1.zip`
- **AAC Tiracon 6V** — German hybrid/digital, metallic FM-like textures  
  - Entries: `AAC Tiracon 6V.zip`, `AAC Tiracon 6V - Version 2.zip`
- **Soviet Cadans S12** — first known Soviet synth dump, dirty and experimental  
  - Entry: `Soviet Cadans S12.zip`
- **Crumar Bit One / Bit 99 / Bit 01** — Italian DCO hybrid synths, dry basses  
  - Entries: several Bit One/Bit 99/Bit 01 dumps
- **Hohner Adam** — arranger with unusual texture samples
  - Entry: `Hohner Adam.zip`

## Obscure drum machines (optional raw-sample extracts)
- **MXR 185 Drum Computer** — raw industrial rhythm data  
  - Entries: `MXR_185 CONTROL 10.zip`, `MXR_185 CONTROL 11 BOOT ROM.zip`, `MXR_185.zip`
- **Bohm Digital Drums / DD16** — German drum sounds + OS variants  
  - Entries: `Bohm Digital Drums.zip`, `Bohm DD16 OS 1.x.zip`, `Bohm DD16 sound EPROMs*.zip`
- **Vermona SK86** — East German primitive machine, brutal electro percussion  
  - Entry: `Vermona SK86 roms.zip`
- **Cheetah MD16** — hard British rave / breakbeat samples  
  - Entry: `cheetah_md16_2.06.zip`
- **E-mu Drumulator** — sampled-drum OS and unofficial EPROM collection  
  - Entries: `E-mu Drumulator OS.zip`, `E-mu Drumulator unofficial sound EPROM collection.zip`

## Pentacle picks for hard genres
1. **Vermona SK86** — best for EBM / industrial / primitive gabber  
2. **MXR 185 Drum Computer** — cold mechanical rhythms  
3. **Jen Synx 508** — aggressive basses + leads  
4. **AAC Tiracon 6V** — unsettling metallic textures  
5. **Cheetah MD16** — hardcore / rave / breakbeat percussion

### Notes
- Many dumps are system firmware/EPROMs, not playable audio — preprocessing is required.
- Some archives may contain raw PCM, wavetables or system code; each one needs verification before embedding.
- Reference URL: https://dbwbp.com/index.php/9-misc/37-synth-eprom-dumps
