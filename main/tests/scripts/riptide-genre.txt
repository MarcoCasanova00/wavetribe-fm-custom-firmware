# Generative genre engine:
#   1) GLO+ARP generates from the current demo pattern's genre
#   2) The GEN page (ARP alone): K1 genre, K2 seed, K3 density, K4 octave,
#      OCT+ generates, OCT- backs out to SEQ.
# MIDI OUT is on, so generated synth notes appear in the MIDI-out log.
# (FM-1 encoders: SELECT=0 ALGO=1 K1=2 K2=3 K3=4 K4=5 PRESETS=6)

100 enc 0 6        # SELECT -> part 6 (lead)
300 btn 1          # OCT_UP -> MIDI OUT on (non-SAVE page)
500 btn 12         # PLAY -> start the sequencer

# --- 1) GLO+ARP generate (TECHNO demo slot 0) ---
700 btn 7          # GLO latch
900 btn 10         # ARP -> generate
1100 btn 7         # GLO unlatch
1500 shot          # SEQ grid after generation

# --- 2a) open the GEN page (ARP alone) ---
1700 btn 10
2000 shot          # GEN page screenshot

# --- 2b) KNOB2 seed bump -> live regenerate ---
2200 enc 3 1       # KNOB2

# --- 2c) KNOB1 genre cycle: TECHNO -> HOUSE -> DUBSTEP (live) ---
2400 enc 2 1       # KNOB1 -> HOUSE
2600 enc 2 1       # KNOB1 -> DUBSTEP
2900 shot          # GEN page after genre changes

# --- 2d) KNOB3 density up, KNOB4 octave ---
3000 enc 4 4       # KNOB3 density
3200 enc 5 1       # KNOB4 octave
3400 shot

# --- 2e) OCT+ generates; OCT- backs out to SEQ ---
3600 btn 1         # OCT_UP -> generate (on GEN page)
3800 btn 0         # OCT_DOWN -> back to SEQ
4000 shot          # SEQ grid again

4500 btn 12        # STOP
4600 btn 12        # PLAY again

# --- 3) MIDI control surface: CC94 genre, CC95 seed+generate, CC96 density ---
5000 midi 0xB0 94 51     # CC94 -> genre 1 (HOUSE) + live generate
5200 midi 0xB0 95 3      # CC95 -> seed 3 + generate
5400 midi 0xB0 96 80     # CC96 -> density 80 + generate
5600 shot                # SEQ after CC-driven generation

6500 btn 12        # STOP
7000 end
