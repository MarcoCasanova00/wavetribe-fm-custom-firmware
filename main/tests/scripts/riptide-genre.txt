#   ARPEGGIATOR page (ARP) / COMPOSE (GLO+ARP) / EUCLID (GLO+SEQ)

#   MIDI CCs 94/95/96 -> genre/seed/density (live)
# MIDI OUT on so generated synth notes appear in the MIDI-out log.
# (FM-1 encoders: SELECT=0 ALGO=1 K1=2 K2=3 K3=4 K4=5 PRESETS=6)
