# voice (GR!MM behavior) - the old note must not keep sustaining after the
# patch switch.  Select a tonal part, play a note (sustain), then switch the
# patch via MIDI CC 93 while the note is still held.  After the switch the
# output must decay to silence (checked against the rendered WAV tail).

100 enc 0 5        # select tonal part 5 (BASS) so MIDI notes reach the FM engine
200 midi 0x90 60 100   # note on, held (sustain) - no note off

# While the note is still held, switch the patch (CC 93 -> patch index ~25)
3000 midi 0xB0 93 25
