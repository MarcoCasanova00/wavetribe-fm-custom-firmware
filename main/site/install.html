2 · Install

  1. Chrome or Edge, FM-1 connected directly by a **data** USB cable.
  2. Close other MIDI apps (editors, DAWs, other browser tabs using MIDI).
  3. Back up your music first: editor → Backup.
  4. Press Install, allow MIDI, and wait for Done. About a minute.
